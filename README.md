# Health Prediction Application

This is a Python-based CRUD application built with Streamlit and SQLite for the Gokul Infocare Task 2 assignment.

## Features
- **Create, Read, Update, Delete** patient records.
- Input validation for Dates, Emails, and Numeric values.
- API Integration for Health Predictions.

## How to Run
1. Install Python on your system.
2. Open a terminal in this folder and install requirements:
   `pip install -r requirements.txt`
3. Run the application:
   `streamlit run app.py`
